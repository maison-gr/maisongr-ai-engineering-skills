# Support

| You want to | Go to |
|---|---|
| Ask how to install or use a skill | [Discussions](https://github.com/maison-gr/maisongr-skills/discussions) |
| Report that an agent still guessed, over-built or claimed checks it never ran | [Agent failure report](https://github.com/maison-gr/maisongr-skills/issues/new?template=agent-failure-report.md) |
| Report a broken install, configuration or document | [Bug report](https://github.com/maison-gr/maisongr-skills/issues/new?template=bug-report.md) |
| Propose a new skill | [Skill proposal](https://github.com/maison-gr/maisongr-skills/issues/new?template=skill-proposal.md) |
| Report a vulnerability | [Security policy](SECURITY.md). Never a public issue |

Before asking, check the [installation guide](docs/installation.md) and the [FAQ](docs/faq.md).

This is a volunteer-maintained project. There is no guaranteed response time outside security reports.
